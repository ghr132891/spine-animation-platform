Spine 动画助手 1.11.1 · 管理员交付说明

交付给同事两项即可：
1. spine-animation-skill.zip 安装包。
2. 可连接的平台地址，例如 http://172.16.7.76:8780。

交付前，由管理员在服务机完成以下配置：
1. 后台 Codex CLI 已安装并登录，平台服务器保持运行。
2. 在平台设置页配置并验证亿创 API Key。所有新生图使用亿创 GPT Image 2.5 Flare（gpt-image-2.5-flare），历史任务保留原模型查询。
3. 在服务机器打开 http://127.0.0.1:8780/settings.html，可启用临时 HTTPS 参考图通道。服务机需官方 tools/bin/cloudflared 客户端；无需对象存储账户、Cloudflare 账户、域名或存储密钥。已有 ready 的 S3 配置优先，仍可选配置 S3 兼容 endpoint、region、bucket、access_key_id、secret_access_key、prefix 与签名链接有效期。只有本机可保存发布配置，凭据不返回客户端。
4. 查询 /api/automation/agent/sources 的 reference_upload.ready。发布器就绪后，仍需完成实际图片发布、远端像素校验、亿创补图结果复查和动作多帧检查，才可分别给出各阶段的成功结论，不能以启用状态代替实测。

使用者安装 Skill/MCP 后，只发送角色图片和动作要求，后续通过自然语言微调。无需登录亿创、复制 HTTPS 链接、提供存储账户或密钥。后台需要补图时自动发布当前原图并缓存；图片合适时不生图。临时通道或可选对象存储仅负责参考图，生成仍使用亿创 GPT Image 2.5 Flare，不回退模型。

临时通道连接独立 loopback PNG 服务器，只允许随机 token 对应的 PNG GET，不开放工作台、目录或其他接口；持有链接者在有效期内能读取对应原图。图片有效期1小时，服务重启后旧链接失效，平台再次使用时自动刷新缓存；S3 过期签名也会刷新。Quick Tunnel 只用于测试与开发，没有 uptime 保证，域名可能随启动改变。服务机与网络须保持运行；它仅供亿创读取参考图，不替代同事连接平台的局域网／VPN。官方说明：https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/

平台默认无需 Agent 令牌，调用者只配置服务地址即可提交、批量制作、微调和下载。亿创凭据、可选存储凭据与后台 Codex 登录由服务器管理。发布器未启用、官方客户端缺失或网络不通且无匹配有效参考图时，平台保留任务、报告管理员需处理的具体原因，不把配置工作交给普通使用者。

安装包不含亿创 Key、对象存储密钥、内部会话签名、个人任务、素材或当前电脑连接配置。无需向同事交付 storage/agent-access-token，也不要把服务端存储配置或密钥放进 ZIP。
服务器地址变化后重新运行安装程序。settings.json 默认只保存服务地址，不作为共享包内容。
管理员如显式启用 SPINE_AGENT_REQUIRE_TOKEN=1 并重启服务，则旧的可选 --token-file 参数仍可用；默认交付流程不需要它。

范围：自动参考图发布接入图片→Spine 动画的补视角／部件；已有 Spine 的 reference 换皮仍需要每个部件的 512×512 画布链接映射，本轮不包含该映射的自动发布。骨架和动作质量仍须按原流程查看多帧预览，不保证任意图片或动作都成功。

1.9.2 默认流程：正面参考先准备侧向行走视角，再生成完整部件图；Codex 检查和修整连接，组装、绑定，检查待机和行走后继续优化。单人准备立绘，袖片归手臂，保留主衣装连续性。检查与微调自动完成；生成质量、原角色还原和自然步态仍以实图验收为准。
