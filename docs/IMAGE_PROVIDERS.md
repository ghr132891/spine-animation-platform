# 配置生图服务

生图平台负责提供图片；Spine 工作台负责准备素材、组装绑定、制作动作和验收。管理员在服务器本机打开 `http://127.0.0.1:8780/settings.html`，选择服务后保存。

## 支持的接口

| 类型 | 管理员填写 | 参考图方式 |
| --- | --- | --- |
| 亿创 | 亿创 API Key；默认模型 GPT Image 2.5 Flare | HTTPS 图片链接，需要图片通道或存储 |
| OpenAI Images 兼容 API | HTTPS API 根地址、API Key、模型 ID | 直接上传 PNG 文件，无需公开图片链接 |

例如供应商支持 GPT Image 2 时，填写它提供的模型 ID（常见为 `gpt-image-2`）。`image2` 只是某些平台的显示名称，不能假设所有平台使用同一个 ID。

OpenAI 官方 API 根地址示例为 `https://api.openai.com/v1`；第三方服务使用其自己的地址和密钥。不要把某个服务的密钥填写给其他服务。更换地址时必须重新填写密钥，模型名和密钥是否有权限以该服务为准。

## 兼容 API 的协议范围

- 文生图：`POST {根地址}/images/generations`，JSON 包含 `model`、`prompt`、`n=1`、`size`。
- 图生图：`POST {根地址}/images/edits`，multipart 表单使用相同字段及 `image[]` PNG 文件。
- 返回：同步 JSON `data[0].b64_json` 或 `data[0].url`（可下载 HTTPS 图片）。保存后的候选仍进入原有部件审查、绑定和动画验收流程。
- 默认尺寸 `auto`；供应商不支持时在设置页选择固定尺寸。`quality`、`response_format` 默认不发送，只有服务文档要求时再设置。
- 使用 Bearer API Key，禁止携带密钥跳转到其他地址。API 地址目前限 HTTPS 公网服务；暂未接入本机／内网模型服务。

协议依据 [OpenAI 图片编辑接口](https://developers.openai.com/api/reference/python/resources/images/methods/edit) 与 [图片生成接口](https://developers.openai.com/api/reference/resources/images/methods/generate)。只支持聊天接口、Responses 工具调用、自定义字段或自定义异步任务查询的服务需要新增适配器，不能保证填写地址后即可使用。

## 保存、费用和恢复

保存兼容 API 配置只验证参数格式，不发送测试生图，也不强制要求服务商提供 `/models`。页面会显示“已保存，实际生图待验证”，不能将其当作已成功连接或已完成美术验收。

首次验证请创建一个有明确预算的任务，分别确认文字生图与带参考图编辑。普通用户仍只需要图片和动作要求；图片会上传到管理员选择的生图服务。文件上传不经过公开参考图通道，但仍会将参考图片发送给该服务。

平台后台执行同步 API 请求，网页提交快速返回任务编号。每个请求保留提交时的服务、模型及私有配置快照，后续切换不改变已有请求。历史亿创任务继续使用亿创查询，API 已收结果可以在服务重启后读取。

只排队、尚未执行的请求可继续执行一次；已经发出但在响应前中断／超时的请求标记“提交结果不明”，不能自动再次收费提交。图片链接已收到但下载失败时，只重试原结果下载。内容审核拒绝停止，不自动改词、换服务或换模型。

`storage/image-provider*.json`、`storage/image-provider-profiles/` 保存本机配置；密钥文件权限为 `0600`，不会返回浏览器或打包到 Skill／成果中。历史配置快照用于已接收任务；由管理员随 `storage/` 一并保护和备份。

## 当前验证范围

已使用本地模拟接口覆盖文生图参数、multipart 原图上传、Base64／URL 返回、历史任务切换、重启读取、失败分类及不重复提交。没有使用新服务的真实付费凭据，因此不能把协议测试标成每家供应商的实图验收。亿创原有配置保持可用，不会因升级自动切换服务。
