# 完整部件优先的图生 Spine 流程

2026-10-13：修正“静态平面切碎后直接绑定”的流程错误。

生成完整素材 → 同坐标定位 → 保存各层完整alpha → 按实际前后顺序叠放 → 静态拼回 → 双向摆臂/分腿诊断 → 骨骼绑定 → 实际idle/walk验收。

## 已实现

- completed_image 保留隐藏重叠，polygon/mask只表示可见原像素归属。
- offset/pins独立于图集格位，导入不逐片缩放。
- layer-overlap和layer-overlap-image提供五姿态诊断及局部重叠统计；正式build要求对应资源的review-overlap通过。
- 生成提示词v20要求独立完整轮廓、袖后衣料和裤腰下插接余量。
- 草稿交付与正式验收分离；真实素材改变令旧验收失效。

数值不能验证完整隐藏造型，当前没有自动语义分割或自动补全模型。完整候选素材仍由配置的生图服务产生并经实际查看。骨骼动作验收仍独立进行。

## GitHub 参考及取舍

- https://github.com/EsotericSoftware/spine-scripts ：官方说明支持将图层精确位置与绘制顺序导入Spine。采用这一坐标/顺序保真原则，未复制脚本；平台直接使用offset、pins和draw_order。
- https://github.com/GenielabsOpenSource/spine-animation-ai ：公开流程包括部件生成、SIFT+RANSAC定位、骨架与draw order、运行时预览。它仍要求可用部件，定位不能补回缺失衣料。本平台同坐标素材不需要额外特征匹配；重绘偏移素材未来可引入匹配作为候选定位，不能自动接受。仓库为PolyForm Noncommercial，未复制其实现或示例素材。
- https://github.com/facebookresearch/AnimatedDrawings ：二维人物动画研究参考，未接入或声称其能解决当前服装/背包隐藏补全。

## 验证

回归测试覆盖：互斥可见分片静态拼回可以正确、但关节零重叠不能正式通过；完整下层像素允许保留到上层后面；改坐标后旧重叠记录失效。绿马甲诊断仍暴露缺片，保留待修结论，不能将平台接口升级表述为该角色已修好。

## 完整素材生成验收（2026-10-13）

新 character-assets 请求启用 complete-assets-v1。GET /api/characters/{id}/prebind 返回内容摘要与缺失项目；GET prebind-parts、prebind-assembly、prebind-spread 返回三张证据图。POST review-prebind 记录 revision、digest、checks（complete_parts/assembly_matches/spread_intact）、verdict、reason。build 包括 draft 均检查此门禁，旧任务兼容。摘要覆盖源图、贴图、定位、层级、设置与遮罩；修改后旧验收不能复用。生成任务仍使用稳定 nonce，未知提交不重发。

不能用数值代替视觉结论；完整性拒绝或组装不合格时停在素材阶段，保留过程页，只有全部通过才制作动作。

## 绑定前修整接口

POST /api/characters/{id}/finish-parts 接受 revision、edits（part、reason、operations）；采用现有 material-finish 的局部操作。保留 before/after 图像摘要及操作报告，不修改部件偏移和关节点，原图保留。修整后清除三项验收，避免旧结论继续有效。

绿马甲修复经验：肩端重复圈边先区分材质与定位，调整完整袖端进入真实袖口，而非不断裁短手臂；白色袖装去底采用更低容差，避免误删内部浅色。裤腰过渡不能仅做 alpha 渐变，否则动画中下层分开会透底。须先有连续裤料支撑，再柔化重叠硬边，并检查真实动画极值。角色特定的裁片、补片与定位只保留在该角色证据中，不作为全局参数。

腿根插接端在摆动时露出方角：只修整已确认会外露的插接端角，保留中心埋入量；不得横切整条腿。静态摆开与真实 walk 的极值都必须复检。白边收边最多一次，鞋底区域不参与；不能将关节缺覆盖误当成白边删除。

2026-10-13 本轮实测：待机和行走结构/接地/循环通过，但 walk 裤腰外侧仍凸出，正式美术验收为 needs_revision。扩大插接端裁剪产生新缺口，已撤回。应分离稳定裤腰覆盖与运动大腿轮廓，定位实际外露层并修正权重；禁止继续扩大裁剪以强行过关。证据见 evidence/green-finish-20261013/validation.json。当前交付为可播放草稿。

## 2026-10-14：连接与遮挡回归

| 问题 | 平台处理与验收 |
| --- | --- |
| 部件残缺、摆开后撕裂 | 保留完整部件/试拼/摆开三项门禁；补足袖后衣料、独立腿鞋和包体，再绑定。可见图案归属唯一不禁止隐藏重叠。 |
| 肩、颈、腿根偏移 | 同坐标定位、短连接余量、髋部固定及渐变权重；连接连续与遮挡正确分开验收。 |
| 后领压住颈部 | 新增 `occlusion-overlay` 原生编辑，使用审查后的局部边界生成前景层，复制源附件网格/权重，排序源层→头颈→前景。保留原像素和动作。 |
| 静态校准与动画不一致 | 新构建记录 `assembly_source`，另存记录 `derived_from_rig`；结果页显示来源版本并说明快照关系，旧版本缺记录时明确未知。 |
| 静态正确、运动遮挡错误 | 新任务 `assembly-connections-v3` 增加前领/后领与运行时一致性三项；颈口行走32帧，待机8帧。腰胯/背包沿用完整轮廓、纹理与覆盖检查。 |
| 重复生成和重复复检 | 优先已有素材及局部拆层，编辑沿用 nonce 幂等；复检缓存包含采样策略版本，换资源/策略后重检，同一资源重复读取复用。 |

拆层操作拒绝动态绘制顺序、源附件独立动画与不兼容附件，须显式适配这些骨架。它不生成缺失像素，也不自动判断语义边界。结构验证、采样和记录约束由平台执行；实际图面、美术遮挡与自然动作仍须看图判断。旧 v1/v2 任务不改写验收结论。

绿马甲回归：平台操作与已验收颈部修复的全部贴图 SHA、骨架几何和动作一致，原资源不变、重复提交返回同一结果、新生图0张。证据在 `evidence/platform-connections-20261014/regression.json`。
