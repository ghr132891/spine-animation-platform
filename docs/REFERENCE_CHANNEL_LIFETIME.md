# 参考图通道生命周期

临时参考图由独立后台进程发布，工作台重启不会主动关闭其 PNG 服务或 Cloudflare 通道。回环 RPC 采用随机密钥，描述文件仅当前用户可读；公网端点仍只能读取带随机令牌的短期 PNG，不暴露工作台、目录或管理接口。

图片继续按原授权期限过期清理。无图片且无调用两分钟后后台进程退出；显式禁用通道会撤销发布。进程崩溃、机器关机或外部网络故障仍可能令链接失效，不能承诺永久可用。供应商提交前检查本张图片的真实回读与像素；另一张图片的健康记录不能替代当前图片。

输出项报告“文件下载失败”时先保留任务编号，查输出项错误、参考链接实际可用性及服务重启时间。没有输出 URL 时不能当作本机下载重试。重新提交是新生成，需要用户已有授权及预算；未知提交不重发，审核拒绝不通过改词或换服务重试。

本次绿马甲实测：退出发布客户端及重启工作台后，同一 URL 仍能回读且像素相同；生成等待期间再次回读通过。旧任务失败与上一轮重启断开通道时间一致，但供应商错误没有说明 URL 所属阶段，因此保留“可能原因”的限定。
