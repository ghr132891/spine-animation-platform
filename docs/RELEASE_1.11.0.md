# 1.11.0

本版将之前本机验证的素材装配、骨骼压力验收和自动动画续作纳入可部署代码。

- 服装模板约束肩髋尺度、开口、插接深度和纹理归属。同源裤料补接与局部拟合优先复用保存素材。
- `repair-connections` 一次事务恢复本部件历史像素、局部修整和前后遮挡，统一重建证据；失败不覆盖原版。腿根切口应恢复完整图面，肩带前景应排除夹带衣料，不能全局侵蚀或把缩小动作当作修复。
- 静态验收后增加实际 Spine runtime 驱动的摆臂、双腿交替、髋转动压力测试。缺少或失败的压力验收阻止正式绑定，诊断不算正式版本。
- 后生成素材通过静态、视角与压力验收后自动绑定，交付草稿并准备动态复检。状态与资源摘要关联，重复触发复用版本。
- 固定阶段有检查点和耗时记录，失败可仅重试素材准备、压力测试、绑定或动态复检，不重新生图、不重启模型。
- 模型进程按任务隔离，默认最多2个并发，`SPINE_AGENT_CONCURRENCY=1..4` 调整。相同任务操作串行。渲染保持受限并发，模型主要负责看图判断和给出定向修复方案，不保证所有首次生成都无需人工检查。
- `spine_image resolution=original`、摆开图 `pose=0..4`、`crop=[x,y,x1,y1]` 和 `zoom=1..4` 保留局部细节；`spine_images` 一次读取最多8项，减少模型往返。放大不是增加真实细节；像素坐标始终以原图为准。
- `VERSION` 为统一版本源；服务端 `/api/version` 与网页页脚显示运行进程加载的版本、提交号和脏工作区标记。skill、MCP和安装包由同一打包脚本生成。

## 更新与复核

保留 `storage/`，更新代码、安装依赖、运行 `python tools/package_spine_skills.py` 后重启服务。核对网页底部版本和提交号。Git源码使用 `git status --short` 确认是否包含本地修改；源码ZIP或release包包含归档标识。未能确认提交号时显示“未知”，不伪造版本一致性。

固定步骤的重试入口位于网页“阶段耗时与失败续作”；对话用 `spine_retry_stage`。生图失败仍遵循旧生成编号恢复、未知提交不重发的规则。模型认证失败不能用固定阶段重试解决，需要修复凭据后继续同一任务。

压力测试与正式动画的所有准备结果均不等于美术通过。旧成果保留；失败候选、剩余问题和实际验收图持续可见。橙衣测试曾发现腿根擦除切口与肩带前景夹带衣料，不能把该失败样本描述为任意角色自动合格。
