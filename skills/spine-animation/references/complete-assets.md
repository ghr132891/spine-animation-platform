# 完整部件先验收，再制作动画

新生成 character-assets 启用 complete-assets-v1。流程：锁定角色和目标视角→明确拆件归属与前后层级→生成独立完整部件→透明提取→逐件放大→试拼→双向摆开→全部通过后绑定。

完整臂连掌、完整腿连鞋保留连续轮廓和关节隐藏余量。主衣装补齐袖后衣料、裤腰保持连续；可见图案归属唯一不等于禁止图层重叠。衣领归主衣装，肖像保留插接区，避免重复领口。背包按穿戴视角；固定配件可按实际设计合并，需要独立摆动时分离。生成图格位仅用于分隔，不能当组装坐标。最终图集由程序打包，不用模型追求紧密排版。

已有合格图优先复用；用户要求实测生成时用稳定nonce实际生成并保留任务。只接入实际看过的裁片与真实连接点，不将标准图直接冒充新生成结果。

平台操作：spine_character action=prebind 获取digest；spine_image依次读取prebind-parts、prebind-assembly、prebind-spread。必要时单独放大part。review-prebind提交当前revision、digest、verdict、reason、checks={complete_parts:布尔,assembly_matches:布尔,spread_intact:布尔}。新任务build包含草稿均要求三项为真且关节非零重叠；素材、连接点或层级变更后重新查看验收。检查证据不能只靠数值。

complete_parts：逐件完整，隐蔽衣料存在，比例/材质/朝向一致，透明边缘不误删。
assembly_matches：与完整角色参考对照，身份、比例、接缝和前后遮挡正确，无重复衣饰。
spread_intact：手臂前后摆开、双腿分开后无露洞和撕裂，背包仍完整。

失败时保留部件与过程页，标记具体缺陷，不进入动画，也不把上版动画当新成果。有效图的质量问题可预算内一次定向修订；内容审核拒绝停止，提交未知只查原任务。合格后再做待机8帧、行走32帧及局部动画验收。

重新绘制的完整部件与原立绘不要求逐像素相等；试拼按角色身份、比例和连接视觉验收。旧可见像素分层的拼回误差仍作诊断，不能要求重绘素材零误差，也不能以此替代三项门禁。

绑定前可以用 finish-parts，参数为 revision 与 edits=[{part,reason,operations}]，operations 使用 material-finish 的局部 alpha 操作。平台保留 before/after 图片与操作历史，并清除旧验收。先区分白底误删与外缘污染；白色袖装应降低去底容差，不能先挖空再靠收边修复。重复肩端边只裁已确认多余区域；裤腰柔化仅用于下方有完整不透明裤料支撑的重叠区，必须摆开复查，不用透明度掩盖缺图。鞋底与合法发丝应避开收边选区。不复制本次人物的坐标和参数到新角色。

肩端重复边先检查袖片是否真正埋入袖口；裤腰渐变之前补足连续下层裤料。腿根方角只修整外露端角并保留插接中心，不横切整腿。静态摆开通过之后，真实 walk 极值仍可能露边；必须以新资源重新渲染复检，不能沿用静态结论。

默认导入已执行同坐标配准。局部补全和前景拆层使用 [装配执行路径](assembly-execution.md) 的 prepare-assembly，不等待动画生成后才修领口。
