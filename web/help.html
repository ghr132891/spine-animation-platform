保持骨骼的换皮流程

导入自己的资源

同时选择一套 .json / .skel、.atlas 和图集中引用的全部 .png，或将保留目录关系的 ZIP 拖入页面。一次导入一个 atlas，可以包含多个 PNG 页。包含多个骨骼 JSON 时，请拆成单独资源包。

三种修改方式

  1. 调色：勾选一个或多个部件，调整色相、饱和度、明度，再应用。每次从原图计算，避免颜色累计偏移。
  2. 替换贴图：下载原部件 PNG，在相同尺寸画布上重绘后上传。原 atlas 的旋转、裁切和偏移会自动恢复。也可以展开“整张图集替换”，替换尺寸与排布一致的整页图。
  3. AI：先连接亿创。“生成材质”不需要上传参考图，会生成材质并填入选中部件，同时保留原图明暗及深色细节。“参考图重绘”需要下载工具生成的参考画布，上传至你已有的 HTTPS 素材存储，再填写 URL。生成结果先作为候选，点击“应用候选图”才修改贴图。

AI 材质填充不等于自动重绘整套角色。参考图重绘也可能改变表面细节的位置，需对照动画检查后决定是否采用。

确认动作并导出

在两侧画布比较所有动作和皮肤，打开骨骼视图可检查结构。点击“校验并导出 ZIP”，工具会检查原 JSON/SKEL、atlas 和其他非贴图文件逐字节不变，贴图尺寸与 alpha 逐像素一致。导出包同时包含 _reskin-validation.json。

透明轮廓始终锁定，适合原体型的服装、花纹、材质和配色修改。扩大帽檐、增加翅膀或改变部件形状属于另一种编辑范围。渲染正常仍需人工检查关节接缝、纹理清晰度及极端姿态。

兼容范围

编辑支持旧式与紧凑式 atlas、多页 PNG、90° 等正交旋转、裁切偏移及带 pma 标记的预乘透明度。预览内置 Spine 3.8 和 4.2；其他版本可以做贴图替换和导出，但需用匹配版本的外部编辑器/引擎检查。旧 atlas 未标记 pma 时不能自动判断原图是否已预乘。

左右朝向与行走

示例角色的原始脚尖朝右。预览向左行走时，在“朝向”中选择“左右翻转”，两个画布会整体镜像，身体、脚尖和骨骼显示同步转向；暂停时也可切换。该设置只作用于预览，导出的源骨骼与动画不会因此修改。接入游戏后，需要按移动方向对整个角色做水平镜像。

内置机器人行走已修正小腿弯曲方向，并用脚踝旋转补偿大腿、小腿的旋转，使脚掌保持接近水平。旧项目另有“快递机器人 · 行走修正版”，继承修正时已有的换皮贴图。

历史记录与保存版本

每次修改都会自动存为一个历史版本。顶部“保存版本”可为当前方案命名；“历史记录 → 编辑版本”能恢复旧方案，恢复时会另存一个新版本，不会抹掉后续编辑。“所有项目”可以重新打开以前导入的角色。

“历史记录 → AI 生成”展示当前项目的全部任务，可查看、下载或重新应用以前的候选图。切换部件或关闭浏览器后，只要本地服务仍运行，就会继续查询并保存结果；服务重启后会继续收集已有任务。它不会重新提交生成。

升级前的项目会保留原图、当前状态和原来可撤销的一步。之前已被覆盖的更早编辑无法重建；升级后的版本都会持续保存。

第二步：骨骼＋贴图

顶部“骨骼＋贴图”进入新流程，从当前项目创建独立方案。修改骨骼位置、旋转、缩放、长度和父子关系；换骨骼名称会同步更新动画引用。需要延长实际肢体时调整缩放，骨骼长度主要影响 IK 和骨骼显示。双骨 IK 须保持连续父子链，可在右侧修改目标骨骼。

“贴图 / 附件”允许上传不同尺寸和透明轮廓的 PNG，也能新增图片附件、绑定骨骼或删除附件。网格附件继续使用原网格、权重和变形动画，新轮廓超出网格时请使用新增图片附件，或在 Spine 中重新蒙皮后上传骨架 JSON。“插槽骨骼绑定”包含删除附件后保留的空插槽。

选择骨骼后，粉色显示选中关节点、骨长与名称，蓝色轮廓显示它影响的部件。可在右侧画布点选关节，与骨架列表同步。点击“初始姿态定位”后，可直接拖动已选的粉色关节点；镜像后也支持拖动。

修改位置、旋转、缩放、长度会即时预览，点击“应用骨骼修改”才写入历史。取消预览可恢复当前版本，切换选择会放弃未应用的预览。名称和父子关系在应用后更新。网格贴图的关联说明按蒙皮权重计算。

每次操作保存完整骨架和贴图，历史可恢复旧版本。初始姿态与原动作可切换对照；左右翻转作用于整体预览。“校验并导出 ZIP”包含 skeleton.json、重打图集、每个部件 PNG 和报告，能在相同版本 Spine 编辑器中导入。

第二步支持 3.8 / 4.2 JSON，SKEL 须先导出 JSON；不支持序列图集，不生成原生 .spine 工程。动作保留原局部曲线，改变结构后须检查全部动作。任意骨架的自动动作重定向尚未接入。单张图片制作新的行走动画请使用第三步入口。

自动动作重定向指将 A 角色的动作迁移到骨骼数量、层级、比例不同的 B 角色，并自动匹配关节及补偿动作。现在可以调整原角色骨架并沿用原局部动作曲线；换成另一套骨架时，需要为它匹配或制作动作。

第三步：单图制作行走动画

打开单图制作页，可以上传 PNG / JPG / WebP，或用已配置的亿创生成一张新角色图。生成使用 GPT Image 2.5 Flare，提交 1 张图；任务和下载结果独立保存在本机，关闭页面不会重新提交。

  1. 使用完成的候选图，检查推荐关节。可打开“显示去背景结果”检查腿间孔洞；“清理双腿间封闭的背景”可开关，白色服装区域应包含在对应部件边界内。推荐点位仅根据透明轮廓比例估算，需要将肩、肘、膝、踝等移到实际位置。左侧 / 右侧指原图画面的两侧。
  2. 查看拆分部件。如果头部、身体或背包串入四肢，展开“修正拆分边界”，选择部件，在原图点击圈定范围，再完成。边界点可拖动；关节附近会保留重叠像素，同一肢体链内采用共享网格与连续蒙皮；不同手臂、腿分别运动，避免接触时粘在一起。
  3. 打开“组装校准”，并排对照原图和组装；选中部件可拖动、调整旋转或缩放，前后移层，检查分离像素块和补全比例提示。校准单位为原图像素，向右／向下和顺时针为正；可单部件复位。保存校准后制作新行走版本，原骨骼与动作曲线不变，较大移动仍须检查关节衔接。
  4. 设置原图朝向、步幅、抬脚高度及周期，点击“拆分并制作行走动画”。切换待机、行走和初始姿态检查结果，左右翻转会同步翻转脚掌。
  5. 每次制作保留独立版本。可恢复原图、关节、边界和组装校准，再制作新版本；之前的骨骼编辑方案保持独立。导出包含 Spine 4.2 JSON、atlas、图集、部件 PNG、原图和关节配置。

当前支持站立且四肢可分辨的人形双足角色，生成按肢体分离的加权网格骨架及新的原地行走曲线；不会迁移另一套骨架的动作。它不生成原生 .spine / .skel，也不自动识别任意姿势或照片。遮挡部分可在“拆分部件”中使用亿创参考原图生成独立部件，检查结果后选择“只补遮挡，保留原图”：已拆出的可见像素和原关节位置保持不变，只补边界内缺失处。关节伸展后仍需检查补全效果，可调整边界、减小动作幅度或去骨骼编辑器补充贴图。

保存与凭据

项目与原图保存在本工具 storage/projects。可撤销最近一步操作或恢复所选原图。亿创 Key 单独保存在本机，验证成功才覆盖旧值；资源导出不包含 Key。更新亿创凭据。

AI 任务只提交一次，等待超时不会重新生成；未知提交结果需在亿创检查。请求被接受不代表图片生成成功，工具会继续检查每个输出并下载有效图片。
